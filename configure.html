ani.pm Hard Sub setup

Upload the module folder to your public file host. Then enter its raw folder URL below to configure the manifests.

Use the folder containing anipm-hardsub.js. GitHub page links with /blob/ will not work.

Replace the matching JSON file on your host with the downloaded version, then add its raw URL under Settings → Modules in Sora or Shirox.

This helper works offline and sends no network requests.
